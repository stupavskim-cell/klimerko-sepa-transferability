# Original source-data provenance

The manuscript analysis uses publicly accessible monitoring data from the Serbian Environmental Protection Agency (SEPA) and a Klimerko network export available to the authors. The repository package intentionally does **not** redistribute the original SEPA annual Excel workbooks or the original Klimerko export until the applicable redistribution terms/licences have been confirmed.

The exact analysis-ready city-day table used in the manuscript is provided under `data/analysis/paired_primary.csv`, together with the meteorological covariates and city-coordinate table. This is sufficient to reproduce the statistical analyses and validation results in the paper.

Before a public release, the authors should add verified source URLs and licence/terms information here. Do not infer redistribution rights solely from public download availability.
